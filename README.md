# The xPack Logger

A Node.js ES module with a generic console logger class.

## Project documentation

For information on how to install and use this project, please refer to the
[project website](https://xpack.github.io/logger-ts/).

## Project source

The source code of the current release is available on
GitHub as [xpack/logger-ts](https://github.com/xpack/logger-ts),
