## Satisfy dependencies

npm install

## Start the compile background task

TypeScript requires a compile step to transform the source code into
JavaScript that can be executed.

The configuration provides a separate command to perform the compilation:

```sh
npm run compile
```

To avoid recompiling manually, the TypeScript compiler can watch the
source files and recompile them when they change. For this, start it in
`watch` mode:

```sh
npm run compile-watch
```

## Language standard compliance

The current version is compiled with TypeScript 6.0.3:

- https://www.typescriptlang.org
- https://www.typescriptlang.org/docs/handbook


The compiler is configured to produce ECMAScript 2020 (`es2020`) files
that can be imported by any other project via `import`.


For more details on how to configure `tsconfig.json`, please see:

- [TSConfig](https://www.typescriptlang.org/tsconfig/)

## Tests

The tests use the [`node-tap`](http://www.node-tap.org) framework
(_A Test-Anything-Protocol library for Node.js_, written by Isaac Schlueter).

With recent versions, tests can also be written in TypeScript.

As with any `npm` package, the standard method to run the project tests
is `npm run test`:

```sh
npm install
npm run test
```

## Tips and tricks

To trace which files module imports resolve to, enable TypeScript
module resolution tracing:

```json
    "compile": "tsc --traceResolution -p ./",
```
