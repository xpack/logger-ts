A typical test result looks like:

<CodeBlock language="console"> {
`% npm test

> @xpack/logger@${customField('releaseVersion')} pretest
> npm run compile && npm run compile-tests

...

> @xpack/logger@${customField('releaseVersion')} pretest-coverage
> npm run lint

...

> @xpack/logger@${customField('releaseVersion')} test-coverage
> tap --show-full-coverage

...

------------|---------|----------|---------|---------|-------------------
File        | % Stmts | % Branch | % Funcs | % Lines | Uncovered Line #s
------------|---------|----------|---------|---------|-------------------
All files   |     100 |      100 |     100 |     100 |
 src        |     100 |      100 |     100 |     100 |
  index.ts  |     100 |      100 |     100 |     100 |
 src/lib    |     100 |      100 |     100 |     100 |
  logger.ts |     100 |      100 |     100 |     100 |
------------|---------|----------|---------|---------|-------------------
`} </CodeBlock>

The compilation, the type check of the tests, and the lint must pass, and
the coverage must be 100% for statements, branches, functions, and lines.

To run a specific test, without the coverage and with the verbose TAP
output, use `npm run test-one`:

<CodeBlock language="console"> {
`% npm run test-one -- tests/tap/040-is-level.ts

...

# No coverage generated
`} </CodeBlock>
