## Installation

The package is available as
[`@xpack/logger`](https://www.npmjs.com/package/@xpack/logger/)
from the public [`npmjs`](https://www.npmjs.com) repository;
it may be added as a
dependency to any TypeScript or JavaScript
project.

The command to install the
**latest** available version of **@xpack/logger** is:

```sh
npm install @xpack/logger@latest
```

To install a **specific version**, specify it explicitly:

<CodeBlock language="sh"> {
`npm install @xpack/logger@7.0.0
`} </CodeBlock>

The package does not provide any executables, and generally there are **no
reasons to install it globally**.

## Uninstall

As with any **npm** package, **@xpack/logger** may be uninstalled
from the project and the dependency removed from `package.json` with:

```console
npm uninstall @xpack/logger
```
