## Obtain project sources

The project is hosted on GitHub:

- https://github.com/xpack/logger-ts.git

<BranchesDetails />

To clone the stable branch (`master`), execute the following
commands in a terminal (on Windows use the _Git Bash_ console):

```sh
rm -rf ~/Work/xpack/logger-ts.git && \
mkdir -p ~/Work/xpack && \
git clone \
  --branch master \
  https://github.com/xpack/logger-ts.git \
  ~/Work/xpack/logger-ts.git
```

<details>
<summary>For development purposes, clone the
`development` branch.</summary>

```sh
rm -rf ~/Work/xpack/logger-ts.git && \
mkdir -p ~/Work/xpack && \
git clone \
  --branch development \
  https://github.com/xpack/logger-ts.git \
  ~/Work/xpack/logger-ts.git
```

</details>

Alternatively, if the repository has already been cloned:

```sh
git -C ~/Work/xpack/logger-ts.git pull
```

:::tip

To contribute Pull Requests, fork the project and ensure that
**Copy the master branch only** is **disabled**.

Use the `development` branch, and direct the Pull Requests to the
same branch.

:::

## Add links for development

By default, to prevent inadvertent changes, npm dependencies are
installed in read-only folders.

However, during development, it is convenient to maintain a writable
instance of the code to enable changes in parallel with the parent
project.

npm allows linking local development folders to the global npm store,
enabling changes to be reflected in dependent projects without
reinstalling.

The process has two steps:

1. Tell the global npm configuration where the local development
   folder is located.
2. Tell the local project to use the linked development folder
   instead of the installed read-only dependency.

The first step requires executing the `npm link` command in the
local development folder, as shown below:

```sh
npm --prefix ~/Work/xpack/logger-ts.git \
  link
```

The result is the creation of a symbolic link in the global npm
store pointing to the local development folder.

For the second step, in the local project, instead of adding the
dependency by installing it, run the command to link it:

```sh
npm link @xpack/logger
```
